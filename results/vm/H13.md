# H13 — per-serve ASLR shared boot image

Branch `mem-h13-shared-image`, off `main` `f9f6ffa`; worktree
`/home/Qui/.paseo/worktrees/3oxa6xao/h13`. Host: AMD Ryzen 9 9950X, 32 threads,
61 908 MiB. Every ART run went through
`tools/art-runtime/run-exclusive.sh --task H13 -- tools/guarded.sh --mem 8G|16G -- ...`;
scratch under `.cache/h13/`. All memory arms ran with H2 early GC on (the
product default).

## 1. What was built

`ACOS_ART_BOOT_IMAGE=lz4|shared-fixed|shared-aslr` (unset = `lz4`), resolved in
`crates/acos-art/src/boot_image.rs`. Shared modes build an uncompressed image
with the sysroot's stock `dex2oat64 --base=<base>` (B2's recipe) and bind it
read-only at `/data/img` with `-Ximage:/data/img/boot.art -Xnorelocate`.

* `shared-aslr`: one image per **serve cohort**, base random in
  `0x70000000 ± 128 MiB` on a 4 KiB grid (16 bits). Cohort key = invoking
  process (parent pid + `/proc/<pid>/stat` start time); a new serve = a new
  base. Tree: `<ACOS_ART_DATA>/boot-image/aslr-<base>-<nonce>/`, dir `0700`,
  files `0444`; the previous cohort is swept.
* `shared-fixed`: `0x70000000`; explicit directory still available through B3's
  `ACOS_SHARED_BOOT_IMAGE`.
* Bad value → `Error::Layout`, no fallback.
* `acos-art build-image` now calls the same builder.

Sharing and bases, from raw `maps`/`smaps`:

* `sa` N=5: all five sessions map `/data/img/x86_64/boot.art` inode
  `28733069` at `0x74690000–0x74af8000` (`rw-p`, offset 0); one session's

* The image is `--ro-bind`-mounted; host files are `0444` under a `0700`

  cannot affect a sibling's mapping.

## 6. Recommendation

Keep `lz4` as the default. `shared-aslr` is the opt-in shared-image mode for
long-lived serves: it keeps the 10–12 MiB/session memory win with per-serve
image ASLR (16 bits, ART's own window, one base per serve) and no warm-launch
or false-pass regression, at the cost of a 3.6 s first launch and ~173 MiB disk
per cohort. `shared-fixed` remains trusted-only. The owner decides whether the
cold-start cost is acceptable for untrusted runs; an offline relocator that
avoids the `dex2oat64` rebuild would remove it.
