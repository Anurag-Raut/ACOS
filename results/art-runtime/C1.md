## 1. What is implemented, method by method

### `android.gui.ISurfaceComposer` (AIDL; `SurfaceFlinger` / `SurfaceFlingerAIDL`)

| code | method | C1 state |
|---:|---|---|
| 1 | `bootFinished` | unchanged (V1) |
| 2 | `createDisplayEventConnection` | unchanged (V1) |
| **3** | **`createConnection`** | **implemented**: reply Status + the installed `android.gui.ISurfaceComposerClient` binder |
| 6, 7, 8, 10, 11, 57 | display queries / `getMaxAcquiredBufferCount` | unchanged (V1) |
| everything else | — | structured `UNSUPPORTED_ANDROID_API` (unchanged) |

### `android.ui.ISurfaceComposer` (legacy, same `SurfaceFlinger` binder)

`Transaction::apply` does not use an AIDL `applyTransaction`; the image's
`BpSurfaceComposer::setTransactionState` writes the token from
`android::ISurfaceComposer::descriptor` (`0xd038f`), i.e. **`android.ui.ISurfaceComposer`**,
and passes **code 8** (`0xd06ae`). The node therefore dispatches on the interface token
*before* the code (code 8 is `getSupportedFrameTimestamps` on the AIDL interface).

| code | method | C1 state |
|---:|---|---|
| **8** | **`setTransactionState`** | **implemented** (decode + apply + callbacks), see §3 |
| 1–7, 9+ | deprecated legacy methods | structured `UNSUPPORTED_ANDROID_API` |

### `android.gui.ISurfaceComposerClient`

Codes are the image's proxy immediates (`createSurface` `0x165d70`, clear `0x166071`,
get `0x1662c7`, mirrorSurface `0x166537`, mirrorDisplay `0x1667a7`).

| code | method | C1 state |
|---:|---|---|
| **1** | **`createSurface(name, flags, parent, LayerMetadata)`** | **implemented**: pops a pre-allocated layer handle, allocates a layer id, replies a full AIDL `CreateSurfaceResult` (`marker, size, binder, layerId, name, transformHint`) |
| **2** | **`clearLayerFrameStats(handle)`** | **implemented**: clears the recorded frame numbers |
| **3** | **`getLayerFrameStats(handle)`** | **implemented**: real `gui::FrameStats` shape (`refreshPeriodNano`, three `long[]`); `actualPresentTimesNano` is empty because nothing presents |
| 4 | `mirrorSurface` | **stubbed**, structured unsupported |
| 5 | `mirrorDisplay` | **stubbed**, structured unsupported |
| 6 | `getSchedulingPolicy` | **stubbed**, structured unsupported |
| other | — | structured `UNSUPPORTED_ANDROID_API` naming the client interface |

**Image fact:** API-34 `createSurface` has **no width/height/format arguments** (only
name/flags/parent/metadata); the size arrives with the first buffer transaction. The
layer record's dimensions are therefore filled from the `GraphicBuffer`, not invented at
creation. W-R §2's `(name, w, h, format, flags, …)` describes an older path.

### `android.gui.ITransactionComposerListener` (reverse calls)

Descriptor is the image's `IMPLEMENT_META_INTERFACE` string
**`android.gui.ITransactionComposerListener`** (UTF-16 literal at `0x1952ac`), not
`…ITransactionCompletedListener`. Tags are the legacy enum (`FIRST_CALL_TRANSACTION` = 1).

| code | method | C1 state |
|---:|---|---|
| **1** | **`onTransactionCompleted(ListenerStats)`** | **queued** for every listener callback id on the transaction |
| **2** | **`onReleaseBuffer(ReleaseCallbackId, Fence, uint32)`** | **queued for the previous buffer** once a newer buffer is applied |
| 3, 4 | queue stalled / trusted-presentation changed | not sent (no queue hang, no trusted presentation) |

## 2. What is real, what is a placeholder

| piece | verdict |
|---|---|
| `createConnection` reply binder | **real host node**; a test asserts it equals `SurfaceState::client_binder` |
| `createSurface` reply | **real image bytes**: AIDL `CreateSurfaceResult` with the inline size word; handle is a routable binder, layer id monotonically allocated |
| transaction token + code | **real image values**: `android.ui.ISurfaceComposer`, code 8 |
| transaction parcel | **decoded to the last byte** in the image's own `layer_state_t` / `BufferData` / `WindowInfo` order (`data_avail() == 0` in tests) |
| `GraphicBuffer` | **real shim wire form**: 13 header words + 9 handle ints (`GB01`, 1 fd), memfd duplicated into the store |
| latest-buffer store | **real**: `fd`, width/height/stride/format, frame number, buffer id, producer id, crop |
| release callback id | **real**: `(GraphicBuffer.id, BufferData.frameNumber)`, exactly what BLAST's `mSubmitted` is keyed by |
| `onTransactionCompleted` stats | **shape real, values synthesized**: latch time is `CLOCK_MONOTONIC` now, no present fence, one `SurfaceStats` for the layer, empty jank data |
| fences | **always no-fence** (`-1`/`Fence::NO_FENCE`), same decision G1 §3 argued for a software producer |
| composition / presentation | **absent**: nothing is composed, nothing is on a display, `latchTime` is not a real latch |
| sync groups (`sync=true`) | **absent**: both sync and one-way transactions reply immediately; `finishDrawing`/`reportNextDraw` cannot wait for a real commit |
| frame stats | `actualPresentTimesNano` is empty; `posted`/`frameReady` are the frame numbers the transactions carried |
| layer-handle pool | **bounded (16)**, pre-allocated because `raw_transact` cannot create a binder; exhaustion is a `BAD_REQUEST` naming the limit, never a fabricated id |

## 3. The transaction parcel, exactly

Decode order (`surface_client::decode_transaction_state`), from the image's
`BpSurfaceComposer::setTransactionState` at `0xd030f`–`0xd083e`:

```text
FrameTimelineInfo                         int32 size + body (skipped; no scheduler)
uint32 composerCount
  layer_state_t (r75 order):
    binder surface, int32 layerId, uint64 what
    float x, y, int32 z, uint32 layerStack, uint32 flags, uint32 mask
    4 floats matrix
    Rect crop
    nullable SurfaceControl x2              (bool + client/handle/layerId/name/hint/w/h/fmt)
    4 floats color
    WindowInfo                              (image shape, §4)
    Region transparentRegion                (int32 size + body)
    uint32 bufferTransform, bool transformToDisplayInverse
    bool borderEnabled, float borderWidth, 4 floats borderColor
    uint32 dataspace
    HdrMetadata                             (int32 size + body)
    Region surfaceDamageRegion              (int32 size + body)
    int32 api, bool sideband (+NativeHandle if true)
    float[16] colorTransform, float cornerRadius, uint32 backgroundBlurRadius
    LayerMetadata                           (marker, count, (uint32 key, byte[] value)…)
    4 floats bgColor, uint32 bgColorDataspace, bool colorSpaceAgnostic
    listeners[]                             (binder + ParcelableVector<CallbackId>)
    float shadowRadius, int32 frameRateSelectionPriority, float frameRate
    byte frameRateCompatibility, byte changeFrameRateStrategy,
    byte defaultFrameRateCompatibility, byte frameRateCategory,
    bool frameRateCategorySmoothSwitchOnly, byte frameRateSelectionStrategy
    uint32 fixedTransformHint, bool autoRefresh, bool dimmingEnabled
    blurRegions[]                           (uint32 + per-region 1 uint32, 5 float, 4 int32)
    StretchEffect (fixed 40 bytes), Rect bufferCrop, Rect destinationFrame
    bool isTrustedOverlay, uint32 dropInputMode
    bool hasBufferData [ BufferData: marker, int32 flags, GraphicBuffer?, Fence?,
                         uint64 frameNumber, binder releaseBufferListener,
                         binder releaseBufferEndpoint, binder cachedToken,
                         uint64 cachedId, bool hasBarrier, uint64 barrierFrameNumber,
                         uint32 producerId ]
    TrustedPresentationThresholds (marker + size + body)
    TrustedPresentationListener   (marker + binder + int32)
    float currentHdrSdrRatio, float desiredHdrSdrRatio, int32 cachingHint
uint32 displayCount
  DisplayState                              (token, surface, what, flags, layerStack,
                                             orientation, 2 Rects, width, height)
uint32 stateFlags
binder applyToken
InputWindowCommands                         (ParcelableVector<FocusRequest>, int32 + binders)
int64 desiredPresentTime, bool isAutoTimestamp
uint32 uncacheCount, per entry (binder token, uint64 id)
bool hasListenerCallbacks
int32 listenerCallbacksCount, per entry (binder, ParcelableVector<CallbackId>)
uint64 transactionId
uint32 mergedCount, per entry uint64
```

`GraphicBuffer` is parsed as the shim emits it: `int32 len=88`, `int32 fdCount=1`,
13 header words (`GB01,w,h,stride,format,layers,usageLo,idHi,idLo,generation,
numFds,numInts,usageHi`), 9 handle ints (`w,h,stride,format,usageLo,usageHi,layers,bpp,
dataspace`), then one `BINDER_TYPE_FD`. The fd is duplicated into `LatestBuffer`; the
parcel keeps its own dup until drop (no leak).

Application: for each composer with a non-null `surface`, the layer record's
`latest`/`latest_listener` are replaced. The replaced `(bufferId, frameNumber)` becomes
the `ReleaseCallbackId` sent to the **previous** buffer's listener; the transaction's
callback ids become `onTransactionCompleted`. Duplicate `(listener, callback id)` pairs
across `layer_state_t.listeners` and top-level `listenerCallbacks` are collapsed so a
synchronous transaction does not fire the same callback twice.

## 4. The image is not the r75 tag (encoded, not guessed)

- **`gui::WindowInfo` is older**: the image's `writeToParcel` (`0x16af40`) /
  `readFromParcel` (`0xaf460`) have **no `contentSize` (two ints)** and **no trailing
  `canOccludePresentation` bool**; after `layoutParamsType` they write frame(4) then
  `surfaceInset`, then the two floats and six transform floats. The tag's reader would
  desync here. `InputApplicationInfo` is written by `writeToParcel` **directly** (size
  word first, no Parcelable marker), unlike every `writeParcelable` site.
- **`FrameTimelineInfo`** in the image also carries only vsync id, input event id, start
  time and the refresh-rate bool (size word 24), not the tag's two extra skipped-frame
  fields. C1 skips it by its size word, so either shape stays aligned.
- **`FrameEventHistoryStats`** has `frametimestamps_previousrelease` **off** in the image
  (writer at `0x12b4c0` has one `uint64` then the fence bool), so the callback stats omit
  the tag's `previousFrameNumber`.
- The `ISurfaceComposerClient` tail is **6 methods** in the image (createSurface,
  clear/get frame stats, mirrorSurface, mirrorDisplay, getSchedulingPolicy), matching the
  tag's AIDL here; the `ISurfaceComposer` tail still differs (V1 §3: code 57 vs 65).
- `SurfaceStats` in the image has the optional transform-hint uint32 plus
  `currentMaxAcquiredBufferCount`, which is what C1 writes (checked against
  `SurfaceStats::readFromParcel` at `0x12bca0`).

## 5. Tests (`tests/surface_client.rs`, 5)

1. `create_connection_and_surface_produce_a_routable_layer_handle` — code 3 returns the
   installed client node; code 1 returns a non-null handle, layer id 1, echoed name,
   `transformHint = 0`, `data_avail() == 0`.
2. `a_hand_built_transaction_decodes_to_the_last_byte` — a full legacy parcel with
   `transactionId = 7` decodes with `data_avail() == 0`, the layer handle/layer id,
   auto-timestamp true.
3. `two_buffer_transactions_release_the_first_and_keep_the_latest` — frame 1 stores
   `(bufferId 100, frame 1)` and completes only; frame 2 replaces it with `(200, 2)` and
   the host queue contains an `onReleaseBuffer` whose decoded `ReleaseCallbackId` is
   exactly `(100, 1)`, `Fence::NO_FENCE`, `maxAcquired = 2`, with no trailing bytes. The
   `onTransactionCompleted` parcel is decoded end to end too: callback id 41, the layer's
   `SurfaceControl` handle, and `previousReleaseCallbackId = (100, 1)`.
4. `an_image_shaped_window_info_decodes_to_the_last_byte` — the non-empty image-shaped
   `WindowInfo` (no `contentSize`, no `canOccludePresentation`, direct
   `InputApplicationInfo` size word) is consumed exactly; a tag-shaped reader would
   leave bytes over.
5. `a_legacy_transaction_on_the_aidl_node_dispatches_by_interface_token` — a truncated
   legacy code-8 body is a structured error, not a silent success on the AIDL code 8.

The reverse-callback queue is drained by `ServiceHost::take_deliveries()`, which
`acos-runtime/src/transport.rs:254` already polls after a transaction. That is the only
host change: `ServiceObject::drain_raw_deliveries` (default empty) plus appending its
result in the dynamic-node branch (`host.rs:126`, `host.rs:690`). Without it a
`raw_transact` handler had no way to enqueue a reverse transaction (the decoded path
returns deliveries in `CallResult`).

## 6. Remaining steps to a live frame

1. **Join the relayout `SurfaceControl` to this registry (W2).** W1's relayout writes a
   structural placeholder handle. Stock `SurfaceControl::readFromParcel` needs
   `(client binder, handle binder, layerId, name, transformHint, w, h, format)` and the
   handle must be a layer handle from `createSurface`, or BLAST's transaction
   `layer_state.surface` will not match a record and `onTransactionCompleted`'s
   `SurfaceStats.surfaceControl` will not match BLAST's pending `SurfaceControl`.
   `registry::install` currently installs this client node beside W1; W2 should have
   relayout allocate through it instead of fabricating a handle.
2. **The peer's `INTERFACE_TRANSACTION` (0x5f494e54)** is still unhandled (W-R §1, V1 §8).
   The C1 path is reached through `getService` + `getInterfaceDescriptor`, which does not
   transact; but `ISurfaceComposer::asInterface` on some paths and future AIDL callers may
   query it. This is a peer prerequisite, not changed here.
3. **Frame capture.** `SurfaceState::latest_buffer(handle)` returns the memfd +
   metadata; the next task mmaps it (stride × height × 4) and compares/writes PNG. C1
   deliberately stops at "the bytes are readable", matching the task's gating.
4. **Sync transactions / `finishDrawing`.** `sync=true` replies immediately and no
   present fence is produced. `ViewRootImpl.reportNextDraw`/`finishDrawing` will still
   need a sync group and a real latch time before `FrameTimeline`/screenshot paths are
   honest.
5. **`onTransactionCompleted` `SurfaceStats` matching.** Once (1) lands, the stat's
   `surfaceControl` binder is BLAST's handle, so `findMatchingStat` stops logging
   "Failed to find matching SurfaceControl"; until then it is shape-correct but cannot
   match.
6. Fences are `-1`/no-fence by construction (G1 §3); a GPU behind the allocator would
   invalidate that return value.
7. `mirrorSurface`/`mirrorDisplay`/`getSchedulingPolicy` are structured unsupported;
   nothing in the launch path calls them.
