## 2. Fixes (all in `crates/acos-services/src/surface_client.rs`)

Size/fd/id/type validation only; no wire or compositor behaviour changed:

1. **Bounds on guest-declared sizes**: buffer geometry ≤ 8192 px
   dimension/stride, `stride*4*height` ≤ 64 MiB with checked arithmetic,
   `stride >= width`; `GraphicBuffer` header 52..=4096 bytes (multiple of 4);
   fd count 0..=8; callback ids ≤ 4096; listeners ≤ 64; composers ≤ 256;
   displays ≤ 16; uncache ≤ 1024.
2. **The same checked geometry at capture** (`capture_latest`, W6 dump), so a
   public `LatestBuffer` can never turn a declared size into an allocation.
3. **fd type validation**: the duplicated descriptor must be a regular file
   **and** anonymous (`/memfd:…` or `… (deleted)`); a linked path, socket, pipe,
   directory or device is a structured `BadRequest` instead of being read as
   pixels by a confused deputy.
4. **No panic on fd exhaustion**: `dup` failure (`EMFILE`) skips the cache entry
   / the stored frame instead of `expect("dup of a memfd")`.

## 3. Tests and teeth

`crates/acos-services/tests/sandbox_c1.rs` (new, 9 tests). Each hostile input is
a real `setTransactionState` parcel through `compositor_client`'s node.

| test | hostile input | assertion |
|---|---|---|
| `hostile_buffer_geometry_is_rejected_before_it_is_an_allocation` | all-`u32::MAX`, height-max, overflow, dimension/stride over cap, `stride<width`, 5000×5000×4 = 100 MB | `BadRequest` naming the geometry bound; generation 0; no capturable frame |
| `an_oversized_graphic_buffer_header_is_refused_not_allocated` | header `len` 16 MiB | explicit `header len` bound (old path: 16 MiB `vec`, then parcel EOF) |
| `a_graphic_buffer_fd_count_bomb_is_refused` | fd count 1000, two fds written | explicit `fd count` bound |
| `a_linked_file_fd_is_not_a_frame` | fd to a still-linked scratch file | `BadRequest` naming the live path; nothing stored |
| `a_socket_fd_is_not_a_frame` | `socketpair` end | `not a regular file` / type error |
| `a_callback_id_count_bomb_is_refused_before_with_capacity` | `CallbackId[]` count 1 000 000 | explicit bound (old path: 16 MiB `with_capacity`, then EOF) |
| `composer_display_uncache_and_listener_counts_are_bounded` | composer 1 000 000 / uncache 1 000 000 / layer listeners 1000 | one explicit bound per vector |
| `a_valid_anonymous_frame_is_still_accepted_and_capturable` | 1080×2209 stride 1088 (real BLAST shape) | control: accepted, generation 1, capture 9.6 MiB |
| `a_short_anonymous_fd_never_becomes_a_partial_frame` | correct type, 1 KiB fd | decodes, `capture_latest()` → `None` (no partial image) |

**Teeth (measured).** With `crates/acos-services/src/surface_client.rs` restored
to `HEAD` and the new test file unchanged:
`7 failed / 2 passed` in 0.09 s. The two passes are the deliberate controls
(valid frame; short-memfd behaviour). The seven failures are the vulnerabilities
themselves:

* geometry: `hostile geometry must be refused: ()` — the old decoder accepted
  all-max/huge/overflow shapes;
* linked file and socket: `a linked path is not a memfd: ()` /
  `a socket is not a frame: ()` — the old code stored them as frames;
* header/callback/fd-count/composer bombs: old code reached
  `parcel underflow` / `object … is not a file descriptor` / `is not a binder`
  (i.e. it *did* allocate/size from the guest word before failing) instead of
  refusing the bound.

The fixed file was restored immediately and the same command is 9/9 green.
