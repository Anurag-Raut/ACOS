## 3. Fixes (all inside `crates/acos-art/src/**`)

| file | change |
|---|---|
| `src/launch.rs` | **`ShortSocketDir`**: peer + logd sockets are bound in `/run/user/<uid>/acos-art-<pid>-<seq>/` (fallback `<repo>/.cache/art-sock/<pid>-<seq>/`), independent of the task name / `--data` length; the sandbox still binds them at `/dev/socket` and `/data/acos-launch.sock`. Removed on drop. |
| `src/launch.rs` | **`HOST_DISK_FULL`**: `disk_free_bytes` (`statvfs`) + `disk_full_for_run` preflight (`ACOS_ART_MIN_DISK_MB`, default 512 MiB) refuses before any guest starts, with an interactive ready line carrying `code=HOST_DISK_FULL, retryable=true`; a mid-session C1 capture write with ENOSPC/EDQUOT now replies `HOST_DISK_FULL` instead of `INTERNAL`. |
| `src/launch.rs` | **`session-exit.json`** written next to the frames on every launch: outcome/code/retryable, guest exit + signal, last stage marker, the guest's own last `ACOSLAUNCH {…}` line (now captured from the guest stdout drain), cgroup + logd notes, free space. |
| `src/launch.rs` | **Panic hook**: a launcher panic writes `code=HOST_PANIC` + the stage to `session-exit.json` and, in interactive mode, emits a structured protocol line — a caller blocked on a reply no longer sees a bare EOF. |
| `src/launch.rs` | **Teardown split markers**: `guest-exit → teardown-streams → teardown-logd → teardown-peer → teardown → teardown-evidence` (inert unless `ACOS_ART_STAGE_TIMING=1`). |
| `src/logd.rs` | **Prompt stop**: `finish_capped` sends a zero-length wake datagram and the reader shortens its timeout once the stop flag is seen; kills the 90 ms idle-timeout join. |
| `tests/w43_session_exit.rs` (new) | 4 tests with teeth: free space readable; a missing path is `None` (never a refusal); ENOSPC/EDQUOT are host-disk-full and ENOENT/EPIPE are not; the preflight refuses only below the threshold. Plus a lib test: stopping an idle logd sink takes < 80 ms (fails without the wake). |
| `tools/art-runtime/load-repro.sh` (new) | The repro/acceptance harness: N concurrent `acos verify --engine art` with bounded CPU spinners, per-session wrapper (session exit status), guest stdout/stderr tee, cgroup `memory.current/peak`, `memory.events` oom/oom_kill/max, `pids.*`, `memory.max`, host loadavg/MemAvailable and free disk; prunes frames/data after every rep (74 MB per 100 sessions). |

## 6. Requests (not mine to change)

1. **W40 / acos-protocol**: register `HOST_DISK_FULL` (`retryable=true`) and
   `HOST_PANIC` (`retryable=false`) as protocol error codes, plus a `retryable`
   field (or a documented `HOST_*` family) so a caller can act on them. Also
   `HOST_MEMORY_LIMIT`, `SECCOMP_UNAVAILABLE`, `GUEST_EXITED` (already acos-art
   outcome codes) deserve the same registration — today the CLI folds them into
   `UNSUPPORTED_BACKEND`/`INTERNAL`.
2. **acos-cli owner**: map a launch/ready reply `code` to a protocol code
   instead of `UNSUPPORTED_BACKEND`/`INTERNAL`; include
   `<artifacts>/art-frames/session-exit.json` in the failure envelope; and do not
   exit 101 with an empty stderr when its own artifact write fails (the ENOSPC
   window produced 9 such runs — a panic message that the CLI's own stderr
   redirect could not write).
3. **tools owners (W41 / bench owners)**: `bench-d2.sh`/`bench-n.sh` should
   (a) check free space before a cohort and report `HOST_DISK_FULL` instead of
   recording app failures, (b) prune per-rep scratch (`.cache/bench-d2/<stamp>/…`
   frames and `data/`) after the summary is written — W43's 5 reps × N=20 wrote
   ~11 GB before pruning, and the 36 GB `bench-d2` tree was part of the 03:23Z
   ENOSPC window, and (c) treat a caller rc of 101 as harness-internal.
4. **W42**: `crates/acos-services/src/surface_client.rs` does not compile in the
   shared tree right now (`missing field 'hidden'` at line 1595 + one type
   mismatch) — W43 built and tested in a clean worktree of HEAD (`aa413a0`).
