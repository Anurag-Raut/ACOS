## 1. Registered codes (protocol + docs/ERROR_CODES.md)

| code | class | retryable | status | hint (short) | exit |
|---|---|---|---|---|---|
| `HOST_DISK_FULL` | `host_guard` | **true** | `blocked` | free space under `.cache/` or move `--artifacts`/`ACOS_ART_DATA`, retry | 1 (CLI) / 2 (acos-art direct) |
| `HOST_PANIC` | `harness` | false | `error` | read `details.session_exit` (stage/panic), report the harness bug | 1 / 2 |
| `HOST_MEMORY_LIMIT` | `host_guard` | true | `blocked` | reduce N/concurrency or free memory, retry | 1 / 2 |
| `SECCOMP_UNAVAILABLE` | `unsupported` | false | `blocked` | fix host seccomp/filter; fail closed, not app behaviour | 1 / 2 |
| `GUEST_EXITED` | `harness` (triage) | false | `error` | read `guest_exit`/`guest_signal`/`stage`; SIGSYS→seccomp, SIGSEGV→app crash | 1 / 2 |

`ProtocolError` now always carries `class` (six values:
`assertion, app_crash, unsupported, harness, infra_timeout, host_guard`,
derived from the code and restored from it on deserialization). Schemas
regenerated; the golden unsupported envelope updated.

## 2. acos-art code → protocol code (one explicit table, `acos-cli/src/failure.rs`)

| art code(s) | protocol code |
|---|---|
| `HOST_DISK_FULL` / `HOST_PANIC` / `HOST_MEMORY_LIMIT` | same |
| `SECCOMP_UNAVAILABLE`, `UNSUPPORTED_SYSCALL`, signal 31 (SIGSYS) | `SECCOMP_UNAVAILABLE` |
| `LANDLOCK_UNAVAILABLE` | `LANDLOCK_UNAVAILABLE` |
| `MEMORY_CGROUP_UNAVAILABLE` | `CONFINEMENT_UNAVAILABLE` |
| `GUEST_EXITED`, `GUEST_EXIT`, `GUEST_EXIT_AFTER_RESUME`, `GUEST_KILLED_BY_SIGNAL`, `NONZERO_EXIT` | `GUEST_EXITED` |
| `NO_LIVE_FRAME`, `NO_FRESH_FRAME` | `NO_FRESH_FRAME` (keeps `LIVE_FRAME_UNAVAILABLE` marker) |
| `TIMEOUT`, `NO_ACTIVITY_RESUMED` | `TIMEOUT` |
| `ART_CRASH`, `ART_FATAL_CHECK`, `ART_FATAL_LOG`, SIGSEGV/ABRT/ILL/FPE/BUS | `APP_CRASHED` |
| `UNSUPPORTED_ANDROID_API` / `NO_TEXT` / `INPUT_UNAVAILABLE` / `RESOURCE_LIMIT` / `BAD_REQUEST` | `UNSUPPORTED_ANDROID_API` / `NO_TEXT` / `UNSUPPORTED_BACKEND` / `RESOURCE_LIMIT` / `INVALID_ARGUMENT` |
| `NO_BIND_REQUEST`, `BIND_NOT_DELIVERED`, `NO_APPLICATION`, `STARTUP_FAILED`, `COMMAND_FAILED`, `INTERNAL` | `INTERNAL` (genuine harness defect; default hint) |
| anything unregistered | `INTERNAL` **with a hint naming the code** (a named harness gap) |

Session loss: `ArtSession::read_line` no longer returns `INTERNAL: session
exited` while a record exists. It reads `<artifacts>/art-frames/session-exit.json`
and classifies from it (concrete code first, then `guest_signal`/`guest_exit`,
refining an `INTERNAL` code when the process evidence names the cause). The
facts (`code, outcome, stage, guest_exit, guest_signal, guest_crash, cgroup,
disk_free_bytes, panic, path`) go into `error.details.session_exit` and into
`verdict.json` + `engine.json` (`session_exit`), including on a pass (the
session is torn down before annotate, so a clean record is present too).

Write/panic paths: `acos-verify` artifact writes map ENOSPC/EDQUOT to
`VerifyError::DiskFull` → `HOST_DISK_FULL` (other write errors stay
`ARTIFACTS_INVALID`); the CLI's own verdict/engine writes go through
`failure::write_artifact` and replace the envelope with `HOST_DISK_FULL` on
failure; `main` installs a panic hook (structured `HOST_PANIC` envelope on
stderr) and `catch_unwind` → exit 1.

## 3. Tests with teeth (`crates/acos-cli/tests/w46_error_taxonomy.rs`, 7/7)

Real `acos verify --engine art` against a fake `acos-art` child, asserting the
exact envelope:
1. every host/harness launch code (`HOST_DISK_FULL`, `HOST_PANIC`,
   `HOST_MEMORY_LIMIT`, `SECCOMP_UNAVAILABLE`, `GUEST_EXITED`) → code, class,
   retryable, status, non-empty hint, `details.art_code` + `details.session_exit`;
2. mid-session reply codes (`GUEST_EXITED`, `TIMEOUT`, `NO_FRESH_FRAME`,
   `SECCOMP_UNAVAILABLE`) are mapped, `details.reply` kept;
3. an unregistered reply code is `INTERNAL` **with a hint naming it**;
4. a bare EOF is classified from `session-exit.json`: SIGSYS →
   `SECCOMP_UNAVAILABLE` (stage/signal in details); `code: INTERNAL` + SIGSEGV →
   `APP_CRASHED`;
5. a passing session surfaces `session_exit.guest_exit = 0` in `verdict.json`
   and `engine.json`;
6. injected ENOSPC (`ACOS_FAULT_INJECT_WRITE=ENOSPC` +
   `ACOS_FAULT_INJECT_ALLOW=1`, a seam; no tiny tmpfs) → `HOST_DISK_FULL`,
   class `host_guard`, retryable, status `blocked`, nonzero rc ≠ 101, non-empty
   stderr naming the code;
7. injected panic seam → rc **1**, non-empty stderr with the `HOST_PANIC`
   envelope and `class=harness` (fails with rc 101/empty stderr before the hook).
