# P1 — M8 input: honest acks, three timings, fast vs strict observation

Worktree `perf-p1-input` (branch of `8e81604`). Owner-approved split from
`docs/decisions/2026-11-12-performance-track.md`: **fast** observation is for
navigation and may be mid-animation; **strict** stays the default for assertions
and pixel checks. Acknowledgement and observed state stay distinct.

## 1. Acknowledgement accounting (`crates/acos-services/src/input_dispatch.rs`)

`InputHost::collect` now matches `FINISHED` replies to the gesture's own input
sequences (`seqs.contains(&ack.seq)`). Focus/touch-mode `FINISHED` replies
queued at window attach are drained and discarded with an `ACOSI2 stale-ack …`
trace line (enabled by `ACOS_INPUT_TRACE`) and are never counted. The reported
`input_ack_ms` / `ack_ms` is the registry's real publish → matching `FINISHED`
latency.

Unit test: `window_session::input_dispatch::ack_accounting_tests::
stale_focus_and_touch_mode_acks_are_never_counted_as_the_taps` queues the two
attach acks before the tap, then asserts the tap returns exactly its own two
sequences, none of them stale, each with a real latency.

Evidence: strict counter tap now reports `ack_ms` p50/p95 **5 / 5 ms** (W55
reported 0 or a stale 1.1 s); fast counter/form tap both report **5 / 5 ms**.

## 2. Three timings and two modes (`crates/acos-art/src/launch.rs`)

`wait_for_settled_observation` takes a mode, the pre-publish tree baseline and
the publish wall clock.

* `strict` (default, unchanged): C1 generation advanced, probe sample after the
  last store, 150 ms quiet, optional pixel-change filter.
* `fast`: first probe tree that differs from the pre-action baseline, then the
  first C1 store after that sample. Bounded window
  `ACOSLAUNCH_FAST_WINDOW_MS` (default 100 ms = two probe periods); if no change
  is seen, the strict quiet rule runs and the reply says
  `state_changed:false`, `bound:"quiet-fallback"`.

Input replies carry `settle: {mode, settled, ack_ms, first_change_ms, frame_ms,
state_changed, bound}` (also copied into `timing.input`), and the frame
reference remains the C1 store bound after the probe. `settle` is plumbed
through `acos_tap` / `acos_text` / `acos_key` / input `acos_action`
(`crates/acos-cli/src/engine/serve.rs`, `art.rs`). There is no scroll/swipe verb
on the ART session; `acos_swipe` remains unsupported, so only existing input
verbs take the option.

`acos_assert` rejects `settle:"fast"` with `INVALID_ARGUMENT`. `acos verify`
assertions, `assert_screenshot` and `assert_region` never pass a settle option
and are strict by construction; a scenario cannot request fast for an assertion
step. Contract documented in `docs/AGENT_API.md` §8.6.1.

## 6. Part 3 — tap + observe in one round trip

The acos-art input reply already carries the settled tree and the bound C1
frame; `absorb` caches both. Rather than a second traversal, `acos_tap` /
`acos_text` / `acos_key` / input `acos_action` accept
`observe: {tree:true, png:false}` and attach the cached tree plus the normal
`frame` reference to the same reply. Live smoke: launch → tree → fast tap with
`observe` returned `settle`, `tree` and `frame` in the tap response.
`observe.png:true` on an input verb is rejected (use `acos_observe`).

## 7. Remaining gaps

1. The strict `tree`/`observe_tree` verb still waits out the ripple (counter p95
   ≈ 990 ms after a fast tap). Fast is intentionally input-only here; extending
   it to `tree` needs an owner decision because a mid-animation tree is not
   assertion evidence.
2. Form fast taps fall back in 6/52 runs when the tree change is observed after
   the last C1 store; the fallback is bounded (≈219 ms p50) and never claims a
   change. A later store would let fast bind, but that is app timing.
3. `GUEST_EXITED` was classified `unknown` by `tools/benchlib.py` (the protocol
   already classes it `Harness`); the table now maps it to `harness`. One reset
   in an earlier run hit it; the final runs have none.
4. No `scroll`/`swipe` ART verb exists, so the settle option is plumbed through
   tap/type/key/action only; `acos_swipe` stays `UNSUPPORTED_BACKEND`.
