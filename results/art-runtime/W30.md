## 3. M11 formula / bar (documented in `tools/run-suite.sh` and in the JSON)

Advisor item 3, exactly as decided:

```
job_gib_min = Σ_samples memory.current_bytes / 2^30 × Δt_s / 60   per job cgroup,
              from job submit to cleanup complete
M11         = verified_good / Σ job_gib_min, at N=10 concurrent, 3 rounds, median
if false_pass > 0: M11 := 0

legacy-derived bar:
  ((206 MiB core / 10) + 112.1 MiB marginal) / 1024 × (19 s / 60)
    = 0.0410 GiB·min/task  =>  24.4 tasks/GiB·min
ACOS must exceed 24.4 × (1 + noise).
```

The runner samples its own cgroup `memory.current` every 100 ms when it is
inside a finite-memory guarded scope (the mandated W30 invocation is), so the
final run has real per-variant integrals:

| field | value |
|---|---:|
| `verified_tasks` | 11 |
| `job_gib_min` | **4.077193** (sum over 22 variant runs; cgroup `memory.current` integral) |
| `m11_tasks_per_gib_min` | **2.6979** |
| legacy bar | 24.4 |
| `false_pass_zeroes_m11` | false (`false_pass=0`) |
| `gate_eligible` | **false** — W30 is a correctness run at **N=1, 1 round**; the gateable N=10 × 3-round M11 belongs to the bench-session suite (advisor items 1/3). |

This number is recorded for cost visibility only; it is **not** a D2/M11 win,
and the report does not present it as one. The typing-heavy tasks dominate
(T07 78 s, T10 49 s, T08 47 s, T12 40 s of 266 s total). When the runner is not
inside a guarded scope, `job_gib_min`/`m11` stay `null` rather than being
estimated (verified with the standalone smoke run).

## 5. First full run → fixes (authoring mistakes, not product passes)

The first full run is kept as `results/bench/suite-20261112T010907Z.json` (exit 1, 7/11 good passes); only `suite-20261112T012551Z.json` is the acceptance result. All four failures were
scenario-authoring errors, each diagnosed from the evidence and fixed; no
product change and no assertion weakening was used to turn them into passes:

| task | first failure | cause | fix |
|---|---|---|---|
| T02 | `assert_log` `increment value=1` failed while logcat had it (ordinal 39) | the executor flushes logs at the start of a step; the `assert_text` between tap and `assert_log` consumed the line into the earlier step's slice, so `since_previous_step` saw an empty slice | put `assert_log` immediately after each tap (W22's own pattern) |
| T06 | after Back, `frag_text` was `Alpha taps=0`, expected `Beta taps=0` | the initial fragment (`showFragment(current, false)`) was never on the back stack, so popping Beta restores Alpha; the expectation was wrong | expect `Alpha taps=0` after Back |
| T07 | `INVALID_SCENARIO`: `text matcher must not be empty` | `assert_text … {exact: ""}` is rejected by validation | assert the cleared error with `{regex: "^$"}` and add `timeout_ms` to the log assertion |
| T10 | `tap` on the already-focused EditText: "tap did not change state in both" | a tap that changes nothing cannot pass the engine's state-change rule; the second tap was redundant | type into the focused editor for beta/gamma instead of tapping it again |

## 8. Residuals

1. **T05 needs a product capability**, not a scenario: an explicit install /
   relaunch command with a caller-supplied app-data root (or a documented
   shared-data mode). Until then it is named UNSUPPORTED.
2. **Dialog-window traversal (T12)** and **provider/service round trip** are
   W27/W28 territory; once the dialog root is in the probe, T12 should assert
   `id/message` + `id/button1` and drop the log-only shape.
3. **Two-activity / startActivity** (T06) remains `UNSUPPORTED_ANDROID_API`.
4. **T03's phone-reference SSIM** is outside the scenario format; the frozen
   live baseline catches rendering regressions but is not a phone-parity gate.
5. The suite is deliberately **N=1, one round**; do not publish its 2.69
   tasks/GiB·min as an M11 result (it is `gate_eligible=false`; the legacy bar is
   24.4 at N=10 × 3 rounds).
6. Wall times are debug-build (`target/debug/acos`, `acos-art`); correctness is
   profile-independent, cost is not. The JSON provenance marks the debug
   binaries `NOT_VERDICT_ELIGIBLE`.
