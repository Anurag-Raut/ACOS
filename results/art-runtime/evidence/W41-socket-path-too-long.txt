W41 evidence: run-exclusive.sh task-name length breaks the ART launcher (2026-11-12)

Symptom: every rep fails immediately (rc=1, ~0.1 s, empty stdout/stderr), the
artifacts dir contains only art-frames/session-timing.json with session_start_ms=0.
`run-suite.sh`/bench drivers see "LIVE_FRAME_UNAVAILABLE: the ART session ended
before its ready line".

Cause (from the acos envelope error, one manual run with a long ACOS_ART_DATA):

  "message": "LIVE_FRAME_UNAVAILABLE: ... startup: acos-art session exited;
   stderr tail: ... acos-art: io: socket path too long"

tools/art-runtime/run-exclusive.sh sets
  ACOS_ART_DATA=$root/.cache/art-locks/data-$task-$$
and the launcher's guest socket path is derived from it, so a long `--task` name
pushes the unix socket path past sun_path (108 bytes).

Name-length bisect (same command, only the run-exclusive --task value changed;
T01 good, pinned target/debug binaries, 2026-11-12T03:29-03:30Z):

  W41-r1                  (6)  pass
  W41-aa-r1               (9)  pass
  W41-T01-x               (9)  pass
  W41-T01-baseline       (16)  pass
  W41-abcdefghijkl       (16)  pass
  W41-T01-baseli-r1      (17)  FAIL  socket path too long
  W41-T01-baseline-a     (17)  FAIL
  W41-aa-baseline-r1     (18)  FAIL
  W41-T01-baseline-r1    (19)  FAIL

Workaround used by W41: --task values <= 16 characters (e.g. W41-T01-1).
Fix (owner: tools/art-runtime/run-exclusive.sh / crates/acos-art): put
ACOS_ART_DATA under a short root (/run/user/$UID/...) or derive the socket path
from a short directory.
