# W37 — shared content-addressed build cache for per-launch ART artefacts (2026-11-12)

**Verdict: DONE (task accepted against its list).** Every per-launch artefact
that does not depend on the APK is now built **once** into
`.cache/art/build-cache/<sha256-of-inputs>/` and every launch only reuses it.
Cold-launch wall (exec → `activity-resumed`) drops from **2205.5 ms p50** to
**654.0 ms p50** (20 launches each, release, benchlib stats) and a fresh N=10
concurrent cohort is **10/10 with 0 `INTERNAL`** (twice).

**Component:** PARTIAL → DONE for build artefacts; `linkerconfig` / classpath
derivation still run per launch (see residuals).
**Evidence scope:** real APK lifecycle (counter, rn-hello, native-hello) on real
ART, release build, one host window shared with W34/W35/W36 agents.

## 8. Residuals / smallest next actions

1. **`linkerconfig` + `derive_classpath` still run per launch** (~100 ms of the
   654 ms; they are bionic sandbox runs that write into `<data>`). Caching them
   needs the same staging-clone treatment (`ArtRoot` with `data = stage`) — not
   done here because the W37 outcome was the compile storm; it also removes the
   last shared-`<data>` write race for bench-d2-style cohorts that share one
   `ACOS_ART_DATA`.
2. **`ensure_system_fonts`** scans/hardlinks the sysroot font set per
   `render-app` launch (idempotent, in the sysroot, not per data). Not cached;
   it is not on the `launch` path.
3. **Cache eviction**: entries are content-addressed and small (shim ~30 KB,
   DEX ~0.5 MB); `.tmp` is swept after 1 h. No LRU yet — same policy as the
   other `.cache` trees.
4. **M3 PASS** needs a quiet host (or the timer moved to `exec`, W33 residual 4).
   Report the M3 first-frame value, not the noisy composite.
5. `bench-n.sh art` (render-app path) was not re-run; bench-d2's real
   `verify --engine art` cohorts are the stronger evidence and were run twice.
