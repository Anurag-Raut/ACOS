# ACOS v0.2.3 — release notes

Patch on v0.2.2 (live view).

- **Fixed:** opening a session in `acos view` (or leaving it and clicking it
  again) showed a black screen until the app next redrew. A viewer that attaches now
  gets the current frame at once, even when nothing on screen changes. Regression
  test `a_viewer_that_arrives_on_an_idle_screen_still_gets_the_current_frame`
  (fails without the fix); live-checked on an idle Gaten session: every visit
  receives a frame.
- **Fixed:** the page's "stream offline · reconnecting…" strip no longer sticks
  after frames or events arrive; watching a session shows only the phone screen,
  scaled to fit the pane (v0.2.2 already had the layout change).

Everything else from v0.2.2 (see `v0.2.2-NOTES.md`), including its known gaps,
is unchanged.
