# ACOS v0.4.1 — release notes draft (2026-11-22)

**Camera2 & CameraX, multi-window split, opt-in Launcher & Settings, Metro dev loop, and hardened shared WebView broker handoff.** v0.4.1 builds on v0.4.0's module architecture with four new modules (`hw.camera`, `multiwindow`, `system.launcher`, `system.settings`), a scenario-driven React Native Metro dev-server step, cold-start relayout fixes, and bounded cross-build WebView broker upgrades.

Status: **NO-SHIP (gate blocked on `origin/modules` `36859df75`)** — RELGATE5 Steps 0, 2 (skip hygiene), 3, 4, 5, 6, 8, and 9 passed, with **2 blockers** before tagging v0.4.1:
1. **Step 1 (`acos-services` test failure):** `mproc_pms::query_intent_activities_matches_every_installed_package` (`crates/acos-services/tests/mproc_pms.rs:219`) fails after `0f930c5af` (`LAUNCHER2`) upgraded `queryIntentActivities` from `Parcelable::Null` to `ParceledListSlice<ResolveInfo>` without updating the test assertion.
2. **Step 7 (idle CPU regression):** `cpu_idle_n5_pct` (`+18.9 %`, `2.10 → 2.49 %`) and `cpu_idle_n10_pct` (`+28.6 %`, `3.59 → 4.61 %`) regressed linearly (`~+0.10 %` of one core per idle session across 3/3 interleaved reps vs `v0.4.0`) while all lattice latencies and memory metrics remained within-noise.

Install: `tools/release/install.sh --prefix ~/.local --register-mcp` (`tools/release/install.sh`, `docs/INSTALL.md`).

## New

### Camera2 & AndroidX CameraX (`hw.camera`, `CAMERA2`–`CAMERA4`, `CAMERAX1`)

- **`hw.camera` hot module (`off`, `stub`, `scripted`).** Publishes `media.camera`, `android.hardware.camera`, and `android.hardware.camera.any` with real `CameraCharacteristics` and Camera2 device/session lifecycle (`ICameraDeviceUser`, `ICameraDeviceCallbacks`), delivering deterministic `ACOS_PATTERN_COLORBARS_V1` frames (`stub`) or host-injected PNG/JPEG frames via `set_frame` (`scripted`) into `ImageReader` and `SurfaceView` preview (`YUV_420_888`, `BLOB`/JPEG, `RGBA_8888`) (`docs/CAMERA_PLAN.md`, `docs/MODULES.md`, `edfd4e949`, `8c31b3e8d`, `9e21d8767`, `922b2c6b4`, `4529927a9`, `34eae3348`).
- **AndroidX CameraX 1.3.4 verified.** `PreviewView` + `ImageAnalysis` + `ImageCapture` work end-to-end on `hw.camera` (`camerax-probe` 21/21 steps; Maven dependencies fetched and sha256-verified by `tools/fetch-camerax-deps.sh` into `.cache/maven-camerax`) (`e6870c38a`).
- **Camera proof scenarios (7 positive + 5 negative):** `camera-probe`, `camera-off`, `camera-capture`, `camera-scripted`, `camera-jpeg`, `camera-preview`, `camerax-probe` all pass; their 5 negative counterparts fail as expected (`05-modules/`).

### Multi-window split (`multiwindow`, `MULTIWIN1`–`MULTIWIN3`)

- **`multiwindow` module + `ServiceHost` guest-command outbox (Slice 1).** Adds typed `GuestCommand::Window` dispatch from `ServiceHost` to the guest launcher, driving multi-window bounds and `windowing_mode` configuration changes (`docs/MODULES.md`, `2f91c2c0b`, `edae2e307`).
- **Proof scenario:** `multiwindow-split` passes (17/17 steps) and `multiwindow-split-wrong` fails as expected.

### Opt-in Launcher & Settings (`system.launcher`, `system.settings`, `LAUNCHER2`)

- **`system.launcher` (`off`, `real`, at-launch).** Stages guest system app `com.acos.launcher` answering `ACTION_MAIN` / `CATEGORY_HOME` and listing `MAIN`/`LAUNCHER` apps via `PackageManager.queryIntentActivities` (`docs/LAUNCHER_PLAN.md`, `0f930c5af`).
- **`system.settings` (`off`, `real`, at-launch).** Stages guest system app `com.android.settings` answering `ACTION_SETTINGS`, `ACTION_APPLICATION_DETAILS_SETTINGS`, and `ACTION_WIFI_SETTINGS` (`0f930c5af`).
- **Proof scenarios:** `launcher-home` (21/21 steps) and `settings-intents` (25/25 steps) pass; `launcher-home-wrong` and `settings-intents-wrong` fail as expected.

### React Native Metro `dev_server` scenario step (`METRO3` / `METRO3b`)

- **`dev_server` scenario step.** Manages a host Metro server lifecycle inside scenarios, defers ART boot when pre-launch `dev_server` is declared, wires host-port loopback forwarding, and verifies clean teardown with zero orphan `node`/Metro processes (`docs/METRO_PLAN.md`, `728d1e1fd`, `95669377f`).
- **Fast Refresh verified 5/5:** `scenarios/metro-reload.yaml` passes 5/5 (12/12 steps, 5–6 s each, 0 orphan `node` processes); `metro-reload-wrong-text` fails as expected.

## Fixes

- **Cold-start pre-visibility `GONE` relayout fix (`LAUNCHER2b`).** Ignores pre-visibility `GONE` relayouts during activity startup so cold-start timing remains flat (`2b821bd97`).
- **Bounded shared WebView broker handoff & stale dir sweep (`WVBROKER1`, ADR-0031 amendment).**
  - EOF probes on the broker socket fail closed immediately instead of spinning `wv-accept` / `write_attach`.
  - Exiting brokers check `(st_dev, st_ino)` before unlinking `broker.sock` so an old broker cannot unlink its replacement's socket.
  - Idle mismatched brokers (`sessions == 0`) are replaced within a bounded window using `SO_PEERCRED` verification; busy or unknown-session mismatched brokers are never killed and trigger build-private fallback (`broker-<source8>.sock`) within a 3 s attach I/O timeout (`a9a486f86`).
  - Verified live in RELGATE5 Step 9: an idle `v0.4.0` broker on canonical `broker.sock` handed off cleanly to `v0.4.1 RC` on run 1 and passed `webview-probe` **5/5** with no fallback socket.
- **Total registered modules:** grew from 24 (v0.4.0) to **28** (`hw.camera`, `multiwindow`, `system.launcher`, `system.settings`); all 28 pass the 6-check conformance kit (`module_kit` 22/22, `modules_doc` 2/2).

## Known limits

- **`metro-reload-full` is best-effort.** Full React Native reloads on RN 0.81 legacy architecture remain subject to upstream `detachRootViewFromInstance` / `setupReactContext` races (`docs/METRO_PLAN.md`, `results/handoff/METRO2/REPORT.md`). In RELGATE5 Step 5, `metro-reload-full` passed **3/3**, but Fast Refresh (`metro-reload`, 5/5) remains the gated dev-loop path.
- **CameraX version scope.** Only **AndroidX CameraX 1.3.4** has been verified (`camerax-probe`, deps pinned in `tools/fetch-camerax-deps.sh`). Other CameraX versions are untested.
- **No `VideoCapture` / camera HAL.** `hw.camera` supports `off`, `stub`, and `scripted` profiles (still capture, `ImageAnalysis`, and `SurfaceView`/`PreviewView` preview); there is no `real` camera HAL profile and no `VideoCapture` / `MediaRecorder` support (`docs/CAMERA_PLAN.md`).
- **Multi-window Slice 1 scope.** `multiwindow` Slice 1 supports single-process window geometry and `windowing_mode` commands (`process == 0`). Multi-process split-screen window-command routing (`process != 0`) returns `UNSUPPORTED_ANDROID_API` and is deferred to Slice 2.
- **Open operational finding (not yet fixed):** `acos-netd` inherits fd 10 (`art.lock`) without `O_CLOEXEC` when daemonizing lazily inside `tools/art-runtime/run-exclusive.sh`, holding the exclusive ART lock until `acos-netd` exits.
