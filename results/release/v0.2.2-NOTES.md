# ACOS v0.2.2 — release notes

Built for agents. Install: `tools/release/install.sh --prefix ~/.local --register-mcp`
(see `docs/INSTALL.md`). Verification for this release was deliberately light
(owner, 2026-11-15: ship fast): crate tests, the 15 gates, Gaten scenarios and
installed-prefix MCP smokes. No A/B was run for this release; the perf merge
carried its own A/B (no regression vs v0.2.1).

## New

- **Live view (`acos view`)**: one local, token-gated URL that lists every live
  session and streams the one you click (half-resolution frames, tap ripples).
  View-only; no input reaches the guest; costs nothing when nobody watches.
  Watching shows only the phone screen, scaled to fit. In T3 Code, open the URL in
  the preview pane and pick a portrait phone viewport (e.g. Pixel 7) for a
  full-height view. Security: 127.0.0.1 only, Host check, socket outside the
  guest sandbox, password text/keys masked, FLAG_SECURE windows blanked
  (stream only; agent screenshots do not honour FLAG_SECURE). `docs/LIVE_VIEW.md`.
- **Action replies say what changed (FB3)**: `acos_tap` / `acos_text` /
  `acos_key` return `result.changes`, the settled UI-tree diff (added / removed /
  changed nodes, activity, focused node). `diff: false` gives the old reply.
- **Typing over MCP works on live sessions (FB1)**: `acos_text` uses the
  guest's own `type_text` path, including React Native `TextInput`s; the typed text
  is echoed only for a known non-password field.
- **Screenshots from MCP (FB2c)**: `acos_observe_tree {"screenshot": true}`
  returns the PNG path, bound to the same frame as the tree.

## Fixed

- Placeholder/skeleton launches need frame evidence (FB2c): an unmounted RN
  skeleton is `PLACEHOLDER_CONTENT` (blocked); a skeleton whose pixels changed is a
  pass with `PLACEHOLDER_SUSPECT`.
- Session hygiene (FB5): idle sessions expire (`idle_ttl_s`, default 600 s) with
  `SESSION_NOT_FOUND details.reason=idle_ttl_expired`.
- A launch opens the APK once (PERF-REL3b/c): Gaten manifest step ~63 ms (was
  ~378 ms).
- acos-mcp: a child that printed past its output limit and exited quickly was
  returned as a truncated success; it is now `OutputLimit`.
- MCP binary discovery prefers the installed sibling over `PATH` and warns once
  when the driven CLI is a different version.
- Agent docs (FB6): `acos_help {"topic":"mcp"}` cheat sheet generated from the
  tool descriptors; launch details moved to the `workflow` topic.

## Known gaps (planned for v0.2.3)

- Back-navigation fixes (ROT8b/ROT9) are not in this release.
- Dogfood findings still open: oversized replies (launch / observe_tree / logs),
  an action reply can be `pass` with `settled: false`, `wait_for` on always-animating
  RN screens, `acos_logs min_priority`, stale RN wording in some docs.
- Live view: the screen stays black until the app next redraws after you open
  it; Enter in a password field can stream the key code (never the text).
