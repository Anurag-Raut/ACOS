# ACOS v0.4.0 — release notes (2026-11-20)

**Android building blocks.** v0.4.0 lets an agent attach the Android system
pieces an app needs, and detach them again. A piece that is not attached
answers with a named error or Android's real missing path. It never gives a
fake success. (`docs/PLAN_2026-11-16.md` §3.1, `docs/MODULES.md`,
`results/handoff/CONFKIT/README.md` §2.)

Status: **SHIP (ready to tag).** RELGATE4 Steps 0–7 passed on `origin/modules`
(`afad66858`), and RELFIX4 resolved the Step 8 installer blocker, shipped
`acos-webview` with an installed `acos doctor` check, bumped the workspace to
`0.4.0`, and passed Step 8 — see "Release gate results" below.

Install: `tools/release/install.sh --prefix ~/.local --register-mcp`
(`tools/release/install.sh`, `docs/INSTALL.md`).

- The installer ships `acos`, `acos-art`, `acos-mcp`, `acos-netd`, and
  `acos-webview` (`tools/release/install.sh`), and installed `acos doctor`
  checks `install_webview` (broker + provider APK).
- It ships `com.android.webview.apk` in `.cache/boot/android-34/system-apps/`
  (`1237365fe`, `tools/release/install.sh`, `docs/INSTALL.md`).
- It carries the `angle-swiftshader` software GL provider when staged in the
  sysroot and records it in `MANIFEST.txt` (`f0e15daa3`,
  `results/handoff/GLSHIP/README.md` §6, `tools/release/install.sh`).
- It ships pinned `pasta` (`2026_10_02.cba3570`, sha256 `314c37e8…edf60`) at
  `libexec/pasta` when present on the host (`8a9560255`,
  `results/handoff/NETREAL/README.md`, `tools/release/install.sh`), together
  with its verbatim upstream licence files (`share/doc/acos/pasta/COPYING`,
  `BSD-3-Clause.txt`) and corresponding source / GPL-2.0 §3 written-offer
  notice (`share/doc/acos/pasta/SOURCE.md`), all listed in `MANIFEST.txt`.
  `pasta` is built from `https://passt.top/passt` (tag `2026_10_02.cba3570`,
  commit `cba357068dc586e7540971eb40bb56c5e62c4de1`), licensed under

## New

### Service modules

Each module owns a set of Android system pieces and has documented profiles
(`docs/MODULES.md`, `results/handoff/CONFKIT/README.md`):

- `off`: the framework takes Android's real missing path.
- `stub`: fixed, documented answers.
- `scripted`: the agent drives the state.
- `real`: a real implementation.

An unattached name returns `UNSUPPORTED_ANDROID_API` naming the module, or
Android's own `null` path where AOSP builds a working manager around it
(`results/handoff/CONFKIT/README.md` §2, `docs/MODULES.md`).

### WebView

- **Fair frame pulls and bundled provider.** Two WebViews do not starve each
  other, and `com.android.webview.apk` ships in the image
  (`results/handoff/WVFAIR/REPORT.md`, `1237365fe`).
- **Taps and input priority.** `webview-probe` passes 10/10 and `webview-fair`
  clicks settle under 1 s in 20/20 runs (worst 529 ms); touches route by point
  and keys by focus (`results/handoff/WVTAP/README.md`,
  `results/handoff/WVTAIL/README.md`, `0faabef02`, `241d2c744`).
- **Named restarts.** Engine restarts report `ENGINE_RESTARTED` with exit status
  and stderr instead of `NO_VIEW` (`results/handoff/WVTAIL/README.md`, `5dbe957d3`).
- **Shared broker outlives its session (`WVSCOPE`, `WVKILL`).** Both are now
  merged into `origin/modules` (`993086d59`, `results/handoff/MERGE040D/README.md`
  §2.3):
  - `acos-webview` spawns in its own `systemd-run --user --scope` unit so
    session cgroup teardown does not kill the shared broker, and falls back to
    the session cgroup with a warning if user scopes are unavailable
    (`results/handoff/WVSCOPE/README.md` §1, `81693fbf6`).
  - Handshake `attach:2` checks build id and refuses stale brokers with
    `BUILD_MISMATCH` (`results/handoff/WVSCOPE/README.md` §2, `81693fbf6`).
  - Engines fork on one process-lifetime thread (`wv-engine-spawner`) so closing
    a session never triggers `PR_SET_PDEATHSIG` `SIGKILL` (`webview-probe` 5/5
    and `webview-fair` 5/5 with 0 engine restarts)
    (`results/handoff/WVKILL/README.md` §2-§4, `d90b47e61`).

### Graphics (software GL and optional host GPU)

Both `glship` and `gpuspike` are now merged into `origin/modules` (`c15f38b3d`,
`4455ad6d5`, `7c5022e41`, `results/handoff/MERGE040D/README.md`):

- **Software GL ships ON by default (`GLSHIP`).** When
  `<sysroot>/gles/angle-swiftshader` is installed, ANGLE on SwiftShader (`OpenGL ES 3.1`)
  is enabled (`ACOS_GUEST_GLES=off` disables it). Launch p50 is 154 ms with it
  on vs 154 ms off (5 reps), and the provider digest is cached in
  `<provider>/.verified` (89 ms once, 0 ms on later launches)
  (`results/handoff/GLSHIP/README.md` §0, §3, §5, `f0e15daa3`).
- **Optional AMD host GPU (`GPUSPIKE`).** `ACOS_GUEST_GLES=mesa-host` (off by
  default) binds the DRI render node via a per-run Landlock plan with Waydroid
  Mesa 26.0.8 and uses the `.verified` cache (`results/handoff/GPUSPIKE/README.md`
  §1, §3, `31dfa9f89`, `results/handoff/MERGE040D/README.md` §2.2). Offscreen GL
  works (1080×2400 heavy shader 2.8 ms vs 17.4 ms on SwiftShader, 6.2×)
  (`results/handoff/GPUSPIKE/README.md` §0, §4).
- **`acos-gles-provider` crate.** Extracted the GL provider contract so `acos-mcp`
  no longer depends on `acos-art` (`7c5022e41`,
  `results/handoff/MERGE040D/README.md` §3).

## Behaviour changes (read this)

- **A declared dangerous permission is not granted.** Install time no longer
  auto-grants dangerous permissions (`c7236c423`, `results/handoff/MERGE040B/README.md`).
- **`tap` with `expect_change: false`.** Claims a tap changed nothing while
  `expect_change: true` still fails honestly (`results/handoff/A11YPACE/README.md` §2).
- **Strict settle `window-reshown` bound.** `hello-views` and `multi-activity`
  now pass (`9a5a7c653`, `results/handoff/BACKSETTLE/README.md`).
- **Honest scenario expectations.** `expectation: unsupported` and pinned
  `expect_error` declare real outcomes, and `needs_env: [pasta]` records
  `skipped_needs_env` when `pasta` is absent (`94b9bb8cd`,
  `results/handoff/SCENHYG/README.md`, `docs/INSTALL.md`).
- **Typed launch extras.** `long` and `float` carry type tags; `Parcelable`
  extras fail with `UNSUPPORTED_ANDROID_API` (`aed14fa1e`,
  `results/handoff/LAUNCHEXTRAS/README.md`).
- **Protocol v4 binder identity and per-app uids.** v4 frames carry sender

  (`71f27e3c8`, `results/handoff/BINDERPID/README.md`,
  `results/handoff/PROCUID/README.md`).

## Known limits

- **Software window canvas cannot draw `HARDWARE` bitmaps.** Direct `View` draw
  throws `IllegalArgumentException` (`results/handoff/GLSHIP/README.md` §0,
  `results/handoff/GATENE2E/README.md` §4).
- **Bubble drag uses `a11y-probe`.** Single-app scenarios cannot launch a second
  app from a bound service, so drag is proven in `a11y-probe`
  (`results/handoff/A11YPACE/README.md` §1b, `results/handoff/GATENE2E/README.md` §4).
- **`angle-swiftshader` ICD provenance gap and `mesa-host` AHB limit.**
  `vulkan.pastel.so` comes from a local image rather than a pinned upstream URL
  (`results/handoff/GLSHIP/README.md` §6), and `mesa-host` fails
  `AHardwareBuffer` / `HARDWARE` bitmap arms (`results/handoff/GPUSPIKE/README.md` §0).
- **Rust VM engine binder callback roots leak.** Exported binders stay rooted in
  `Vm::native_roots` (documented with a sized plan, not fixed; `162d86a0f`,
  `results/handoff/BINDERREF4/README.md`).
- **`net.wifi` and `media.session` limits.** No real radio; `net.wifi` refuses
  `WifiNetworkSpecifier`/hotspot/P2P/RTT/passpoint, and `media.session` refuses
  `getActiveSessions`/media-key dispatch/queue/volume (`results/handoff/MODFILL/README.md` §4).
- **Full RN `/reload` is best-effort and `scenarios/metro-reload.yaml` is absent.**
  Legacy RN teardown races `addRootView`, and scenario YAML has no host
  dev-server step (`results/handoff/METRO2/REPORT.md` §4, §6-§7).
- **Live phone replay for `PARITYFIX` F1 is still open.** The physical phone was
  detached during `PARITYFIX` (`results/handoff/PARITYFIX/README.md`).
