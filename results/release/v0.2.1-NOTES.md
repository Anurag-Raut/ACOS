# ACOS v0.2.1 — release notes (2026-11-15)

For agents using the installed ACOS (MCP `acos-mcp`, CLI `acos`).

## New / fixed
- **Tap by text on React Native**: `acos_tap {"text": "Analytics"}` resolves the accessible name
  (text, else content_desc) among user-visible nodes, like a real device. Assertions stay field-exact.
- **Screenshots are ~100× smaller**: captures are compressed lossless PNG (10.4 MB → ~80 KB); MCP
  image replies are a bounded preview (≤1280 px / ≤512 KiB) plus the path to the lossless file.
- **Verify artifacts you can trust**: each `capture` step's `name` is kept (step JSON, file name,
  `verdict.json` `captures`), assertions echo `expected` and `actual` on pass too, messages show
  selectors as `text=="X"`, `verdict.json` has `status`.
- **Unsupported ABI** is reported before the guest starts (`UNSUPPORTED_ABI`).
- **Content settle** (`settle: content`) for screens whose tree is stable while pixels animate; such a
  frame is never pixel or geometry evidence (a pixel/bounds assertion bound to it fails closed).
- **Rotation**: `rotate` works end to end; system bars follow DisplayPolicy.
- **acos-mcp drives its own install**: it uses `ACOS_BIN`, else `$ACOS_HOME/bin/acos`, else the `acos`
  next to it, else `PATH` — a second install can no longer silently drive another version.
- New error code `ZYGOTE_DEAD` (opt-in zygote mode only).

## Behaviour changes (read this)
- **A run owns its `--artifacts` directory.** A second `acos verify` / `acos_verify` into a non-empty
  directory you NAMED is refused with `INVALID_ARGUMENT` naming the previous run id; use a fresh
  directory or `--overwrite` (MCP `"overwrite": true`). Without `--artifacts` the default
  `out/<scenario stem>` is simply replaced on a rerun.
- `repro.sh` takes the replay's artifacts directory as its required first argument:
  `sh repro.sh /path/to/new-dir`.

## Known limits
- `back` on real ART: the framework back path runs, but the `back` step still times out when the
  last window closes (fix in progress).
- Live typing into a running session (`acos_text`), `content_desc` selectors, MCP screenshots via
  `acos_observe_tree`, the live view (`acos view`) and per-action diffs are in progress (next release).
