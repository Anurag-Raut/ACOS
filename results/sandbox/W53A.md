Date: 2026-11-11. Base: `a62c009`. Worktree `.cache/wt-w53a` (built at
`b4d8a7b`, then 3-way rebased onto `a62c009`).

## Deliverable

New crate `crates/acos-sandbox` — the only ACOS crate allowed to hold the
`unsafe`/`libc` calls needed to enter a sandbox. No sudo, no kernel/system
changes. ADR: `DECISIONS.md` **ADR-0022** (ADR-0021 was taken by W54-A's JNI
thread-attach ADR).

Public API: `probe()` / `Capabilities`, `ConfineProfile`, `confine()`,
`ConfinementReport`, `confine::confinement_active()`, `probe_live()`,
`for_tests_without_confinement` loader override.

## Test harness (separate process, own test binaries only)

`cargo test -p acos-sandbox` runs `sandbox_child` and asserts:

* permitted: `open_ro` (read-only root), `write_data` (data dir), `threads`
  (`clone`), `mmap_exec` (`PROT_EXEC`), `futex`;
* denied (`EACCES`): `open_outside`, `write_ro`, `write_outside` (Landlock),
  `exec`, `ptrace`, `socket(AF_INET)`, `process_vm_readv` (seccomp);
* baseline without confinement: the denied actions above succeed.

Results: `cargo test -p acos-sandbox` → 4 unit + 3 integration pass.
`cargo test -p acos-native-loader` → all pass, including the new
`default_config_refuses_without_active_confinement`.
`cargo check --workspace --all-targets` → green.
`cargo clippy -p acos-sandbox -p acos-native-loader --all-targets -- -D
warnings` → clean. (`acos-cli` has pre-existing clippy errors in
`native_inventory.rs`/`observe_tree.rs`, untouched by this change; none in the
new `sandbox_probe.rs`.)

`acos sandbox-probe` (JSON) reports all nine layers active (see the layer table).

## Integration

* `acos-native-loader`: `LoaderConfig.require_confinement: bool` (default
  `true`); `Loader::load_bytes_named` refuses with
  `LoaderError::ConfinementRequired` (code `CONFINEMENT_UNAVAILABLE`) unless
  `acos_sandbox::confinement_active()`. Test-only
  `LoaderConfig::for_tests_without_confinement()` used by the loader's own
  tests/examples and the `acos-jni` native-fixture test. Existing tests were
  updated mechanically (this is why the native-loader test set is touched).
* `acos-cli`: `acos sandbox-probe` subcommand (`crates/acos-cli/src/sandbox_probe.rs`)
  always emits the standard JSON envelope.
* No untrusted APK/native code was run; only the crate's own test binaries.
