## Status legend

- **Full** — every `Parcel.write*` call in the real method is represented (inheritance flattened through `invoke-super`).
- **Prefix** — the leading fields are in the real order; the remainder is a documented gap (squashing, `SparseArray`, `Parcelling`, typed-array tails).
- **Curated** — an ACOS-owned value whose Java reader is not on the V1 service path.

## Exception codes

The `Parcel.EX_*` constants are read directly from the `android.os.Parcel` static fields in the boot DEX (`parcel_exception_constants_match_the_framework`), and `exception.rs` round-trips all ten header codes.
