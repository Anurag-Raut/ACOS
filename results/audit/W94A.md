* `crates/acos-render/tests/corpus.rs:148` — `eprintln!("SKIP …")` then

## 2/3. S2 — Guest-controlled sizes in `acos-gles` allocate unbounded host memory

`acos-gles` is installed into the confined guest process (and is also used
in-process by `egl_swap_frame.rs`). All checks below only enforce `> 0` /
`>= 0`; `MAX_DIM` (4096) and `MAX_UPLOAD` (64 MiB) are **not** applied on these
paths.

* `glTexImage2D` (`gl.rs:1026`) — `if level < 0`, then
  `gl.rs:1064 let idx = (level-1) as usize; t.mips.resize_with(idx+1, …)`. With
  `level = i32::MAX` the Vec of 32-byte tuples requests ~64 GiB. Same at
  `copy_tex_image_2d` `gl.rs:1190`.
* `glCopyTexImage2D` (`gl.rs:1152`) — no `MAX_DIM` bound before
  `copy_region` → `gl.rs:1278 vec![0u8; width*height*4]`.
* `glReadPixels` (`gl.rs:1909`) — `width,height` only `> 0`; `gl.rs:1943`
  allocates `width*height*4` and `ffi.rs:1573` then `write_bytes` the whole
  result to the guest pointer.

**Repro (unit).** `ffi::gl_tex_image2d(c::TEXTURE_2D, 2_000_000_000, c::RGBA, 4,
4, 0, c::RGBA, c::UNSIGNED_BYTE, 0)` → `t.mips.resize_with(2e9)`; observe abort
under the default `RLIMIT_AS = 4 GiB`. For readpixels:
`ffi::gl_read_pixels(0,0,100_000,100_000,c::RGBA,c::UNSIGNED_BYTE,ptr)`.
**Patch.** `results/audit/patches/94A_gles_alloc_bounds.patch` (adds
`MAX_MIP_LEVEL = 31`, bounds `read_pixels`/`copy_tex_image_2d` to `MAX_DIM`;
`git apply --check` clean).

## 4. S2 — GLSL nested-`for` exponential blow-up

`FOR_ITERATION_CAP = 4096` is applied inside `Stmt::For` (`glsl.rs:1295`), but
nesting is accepted (`glsl.rs:668` parses a bare `for` as a loop body, and
`run_body`/`run_stmt` recurse). N nested loops ⇒ `4096^N` iterations with no
aggregate budget, and a fragment shader runs this per pixel. `while`/`do` and
`break`/`continue` are rejected, but that does not bound nested `for`.

**Repro shader** (parses, `GL_COMPILE_STATUS = true`, then hangs the draw):
```glsl
precision mediump float;
void main(){
  float s = 0.0;
  for(int a=0;a<4096;a++)
  for(int b=0;b<4096;b++)
  for(int c=0;c<4096;c++)
  for(int d=0;d<4096;d++) s += 0.0;
  gl_FragColor = vec4(s);
}
```
**Fix sketch.** Give `Interpreter` a single `Cell<u32>` iteration budget shared
across the whole `run_body`/`run_body` recursion (decrement on each loop
iteration, error when exhausted), or cap nesting depth in the parser. A
per-loop cap alone is insufficient.

## 5. S2 — MCP native-session temp root: predictable name, default perms

```rust
// session_backend.rs:983
fn native_session_root(seq: u64) -> PathBuf {
    if let Some(root) = std::env::var_os("ACOS_SESSION_ROOT") { return PathBuf::from(root); }
    std::env::temp_dir().join(format!("acos-mcp-native-{}-{seq}", std::process::id()))
}
// session_backend.rs:168
std::fs::create_dir_all(root.join("data/user/0"))
```
`create_dir_all` uses the process umask (typically 0755), there is no
`set_permissions(0o700)`, and the name is predictable from the parent pid. A
local attacker who can write `/tmp` can pre-create the directory (or a symlink
to one) so `create_dir_all` succeeds; the Landlock `--rw` grant and later
`remove_dir_all` then operate on attacker-chosen contents. App data under
`data/user/0` is left world-traversable while the session lives.
**Patch sketch.** `std::os::unix::fs::DirBuilderExt::mode(0o700)` +
`create_dir` (not `create_dir_all`) after verifying the parent, or
`mkdtemp`-style `O_EXCL`.

## 6–11. S3 details

* **MCP child stdout (S3)** — `session_backend.rs:911` `read_line(&mut line)`
  grows `line` without a cap; `serde_json::from_str` then parses it. Guest
  native code runs in the child and can write an unbounded line to fd 1. Cap
  with `Read::take(MAX_FRAME)` or `BufRead::read_until` + length check.
* **JNI `GetEnv` (S3)** — `jni.rs:2456` `minor > JNI_VERSION_1_6 as u32`
  compares a 16-bit minor against 0x0001_0006, so `GetEnv(0x0001FFFF)` returns
  `JNI_OK`. Should be `minor > 6`. Patch:
  `results/audit/patches/94A_jni_getenv_version.patch`.
* **Landlock `/dev` (S3)** — `rn_hermes.rs:139` `.with_read_only("/dev")`
  grants `READ_FILE` on every device node, not just `urandom`. The inline
  comment claims Landlock cannot target character devices; even if true for
  `add_rule` on a device fd, the directory rule is broader than needed. Test
  harness only (production `native_launch.rs` does not do this).
* **Provider policy (S3)** — `ams_java.rs:580..585` sets `exported = true` and
  `readPermission`/`writePermission = null` regardless of the manifest, while
  `pms.rs`/`ProviderInfo` now parse `exported`/permissions. Single-app blast
  radius today, but it is a caller-identity policy bypass.
* **Root/IR leaks (S3)** — `binder.rs:151` `LOCAL_OBJECTS` has no removal path;
  `transport.rs:104` calls `vm.root_handle(obj)` on every `binder_id_of`;
  `bridge_root` (`javabridge.rs:518`) pushes unconditionally with no dedup, so
  `native_roots` grows on every repeated map. Separately, `exec.rs:225`
  `static CACHE` pins every lowered `Program`/`MethodCode` forever (no
  eviction). Both matter for long-lived MCP sessions.
* **Host guard (S3)** — `limits.rs:91..103` returns early before the wall-clock
  check, so a watchdog can be crossed after up to 63 further allocations. The
  doc comment calls the ceilings “hard”. Patch:
  `results/audit/patches/94A_host_guard_wall_every_call.patch` (evaluate the
  wall clock every call; keep only the `/proc` read amortised).

## 12–15. Honesty / docs

* **Render corpus circularity (S3).** `corpus.rs:1..30` documents the scenes as
  a “DisplayList/Canvas reconstruction”, and W82A §1 says the dialog panel
  bounds/colour were *measured from the reference*; thresholds are “calibrated
  from the measured values”. This measures the rasteriser against a hand-built
  approximation, not a VM-drawn frame. Disclosed in W66A/W82A §“honest”, but
  `STATUS.md`'s landed table quotes “5 fixture scenes vs ART (SSIM
  0.989-0.995)” without the qualifier.
* **GLSL doc/stub (S3).** `glsl.rs:17` still lists `for`/`while` as rejected
  although `for` is implemented; `glsl.rs:1636` `matrixCompMult =>
  Value::F(0.0)` silently returns the wrong type/value instead of an
  `unsupported` rejection; `glsl.rs:1198` `call()` never dispatches a
  user-defined function (`glsl.rs:1196`), so `glCompileShader` reports success
  (it only calls `glsl::parse`, `gl.rs:467`) for a shader that then errors on
  every draw.
* **ADR/doc drift (S3).** `glsl.rs:1`, `benches/frame.rs:4`, W86A and W92A cite
  “ADR-0023” for software GLES, but `DECISIONS.md` ADR-0023 is “Typed-IR
  slow-op trampoline”. `STATUS.md:3` (“HEAD `9ad95e7`, 87 commits”) predates
  every commit in this range.
* **Bench evidence naming (S3).** `w83a-before.json` and `w83a-after.json`
  differ only in `label` and whether `ir_ms` is `before_ms` or `after_ms`; they
  are one interleaved run, not independent before/after measurements. The
  quoted 1.41×/2.61× rows do match `after_ms`.

## Considered and found sound

* **IR trampoline exception/GC semantics.** `run_ir` positions the frame at the
  slow op before dispatch, releases the frame borrow for every VM-touching op,
  routes `JavaException` through `handle_exception`, and re-checks `fi <
  frames.len()` before restoring the cached program. Ref bits are set on every
  object-producing op (`move-object`, `move-result-object`, `aget-object`,
  `iget-object`, `sget-object`, `new-instance`, `new-array`, `const-string`).
  `ir_equivalence.rs` runs general-vs-IR with and without GC stress (27
  fixtures present locally). The only caveat is the missing fixture gate (#1).
* **Binder re-entrancy.** `with_transport` now takes a shared borrow and
  `dispatch_local_binder` clones `Parcel`s out of `parcel::with_store` before
  calling in, so the nested `with_store` is not a double `borrow_mut`. Provider
  CRUD goes through the framework's own `ContentProviderNative`/proxy rather
  than a hand-written codec.
* **`native_bridge` extraction.** `extract_native_lib` rejects `..`/`/`/NUL`,
  re-checks `target.parent()`, and caps the decompressed size by the archive
  length and 256 MiB. No zip-slip found.
* **bionic stdio shims.** `acos_map_stream` fails closed with `EBADF` for
  unknown pointers, registers host `FILE*`s, and `__fwrite_chk` checks null.
  `popen` is a shell escape, but the guest is arbitrary native code and
  fork/exec are already seccomp-gated.
* **`acos serve` IPC.** Not landed; `session.rs` and `docs/AGENT_API.md` say so
  explicitly. No peer-cred/0700 review possible.
