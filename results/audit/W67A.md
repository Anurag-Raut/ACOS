native/JNI working-tree additions W57/W61/W64/W65/W66 are landing). No source
file was edited. Failing-test proposals are patches under
`results/audit/patches/`; they are not applied. Ground rules are the same as
`HONESTY_AUDIT.md` §1 (Android parity or an explicit `UNSUPPORTED_*`; no silent
success; guest input never sizes a host allocation; least privilege).

## What W35-A (commit `ccd7ee7`) did fix (re-verified)

* `getenv`/`setenv`/`unsetenv` now use a seeded guest table
  (`natives/io.rs:84-94`), so the host environment is no longer readable.
* `Unsafe.park`/`unpark` are real green-thread parks (`natives/unsafe.rs:112-160`).
* `read_string16_array` bounds `n` by the remaining payload
  (`acos-parcel/src/parcel.rs:712-736`); the typed-array reader calls `check`.
* `IAppOpsService.checkOperation` now maps restricted ops without a grant to
  `MODE_ERRORED` (`acos-services/src/declared.rs:100-140`).
* `dlopen` absolute/host paths are canonicalised and confined to `search_paths`
  (`bionic/dl.rs:249-267`) — but `DT_NEEDED` was missed (finding #4).
* `results/audit/patches/{01..04}` from HONESTY_AUDIT are reflected in code or
  superseded (fixtures gate, parcel, AppOps, UserManager).

## Legitimate / verified-clean in this range

* `acos-render` SSIM correction (`diff.rs`): f64 moments and standard
  `0..255`-scale `C1`/`C2` are a genuine bug fix; the tightened
  `reference_diff.rs` thresholds compare against the committed ART capture.
* `acos-sandbox` reports layers from real kernel return values; `confine`
  fails closed when a required layer is inactive (verified `CONFINEMENT_*`).
* `acos-apk` zip-slip: `parse_lib_name`/`safe_component` reject `lib/<abi>/../`
  entries before extraction, and the joined target is re-checked.
* `acos-services` AppOps/parcelable/AMS changes record state and return
  `UNSUPPORTED_*` on mutators rather than faking.
* `BENCHMARKS.md` §8.10 states `app_created=0`/`transaction_delivered=0`
  explicitly and labels the launch metric `not-comparable` — honest.
